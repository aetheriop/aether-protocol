# Aether Protocol

[![CI](https://github.com/aetheriop/aether-protocol/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/aetheriop/aether-protocol/actions/workflows/ci.yml)

Публичная эталонная реализация шлюза моделей и расчётных правил Aether AI. Репозиторий содержит запускаемый прототип шлюза, отдельно проверяемые правила расчёта и общий код симуляторов сайта. Фактические параметры участия и расчёты с участниками определяются условиями конкретной позиции.

## Путь задачи

```text
queued → production → QA → invoiced → settled
             │           │               │
             │           │        сверка полученной оплаты
             │           └── приёмка результата
             └── шлюз моделей → учёт токенов и расходов

Полученная оплата − расходы − резервы → база распределения
База → доля маржи участника
Активный капитал × отдельная ставка → вознаграждение за оборот
```

| Раздел | Что можно проверить |
| --- | --- |
| [gateway](gateway/) | Шлюз `POST /v1/chat/completions` для ответов без стриминга, отзыв ключей, журнал токенов и расчётных списаний. |
| [settlement](settlement/) | Расчёт окна, лимит резерва, очерёдность по траншам и понижение ставки за оборот после разблокировки. |
| [ledger](ledger/) | SQLite-схема бюджета, списаний, полученных платежей и событий перехода между статусами пакета. |
| [policies](policies/policy.json) | Пример лимитов расходов и настройки очерёдности. |
| [simulator](simulator/index.js) | Функции расчёта окна пула и экономики пакета, используемые на сайте. |
| [tests](tests/) | Сверка расчётов, расходование бюджета, списания, отзыв ключей и проверки обоих симуляторов. |

### Как считается окно

Оплата в 1 000 USD за вычетом 420 USD за модели и инфраструктуру, 180 USD за проверку и доработку и 100 USD за комиссии и возвраты даёт маржу 300 USD. После резерва 60 USD остаётся 240 USD. При убытке или резерве, исчерпавшем остаток, база равна нулю.

Приоритеты в `waterfall.py` настраиваются явно. В примере `policy.json` Frontier первым принимает списание. Вознаграждение за оборот применяется к активному капиталу. После разблокировки пример использует половину базовой ставки. Эти сценарии тестируются отдельно от пропорционального примера на главной.

- [Методика расчётов](https://aetheriop.com/ru/methodology)
- [Калькулятор окна пула](https://aetheriop.com/ru/pool-plans#rates)

## Локальная проверка

Требуются Python 3.11 или новее и Node.js с поддержкой встроенного `node:test`.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --test tests/simulator.test.js
```

Тесты шлюза используют локальную SQLite и имитацию ответа провайдера. Проверка CI запускается на каждом push и в pull request.

## Запуск шлюза

1. Выпустите клиентский ключ командой `python -m gateway.auth --database gateway.sqlite issue`. Сохраните выданный токен и идентификатор ключа.
2. Задайте переменные окружения. `AETHER_PROVIDER_URL` содержит HTTPS-адрес API провайдера до `/chat/completions`, `AETHER_PROVIDER_KEY` содержит его ключ, `AETHER_GATEWAY_DB` задаёт путь к SQLite.
3. Задайте `AETHER_MODEL_TARIFFS` как JSON вида `{"model-id":[1000000,2000000]}`. Пара означает стоимость миллиона входных и выходных токенов в микродолларах USD. Пример соответствует 1 и 2 USD за миллион токенов.
4. Запустите `python -m gateway.api`. Процесс слушает `127.0.0.1:8080`.

```sh
curl --fail-with-body http://127.0.0.1:8080/v1/chat/completions \
  -H "Authorization: Bearer ${AETHER_CLIENT_TOKEN}" \
  -H "Content-Type: application/json" \
  --data '{"model":"model-id","messages":[{"role":"user","content":"Summarize this task."}]}'
```

Ответ содержит `X-Request-ID`, по которому можно сверить запись в `usage_entries`. Отозвать ключ можно командой `python -m gateway.auth --database gateway.sqlite revoke KEY_ID`.

Расчётные модули и пример политики выполняются локально. Шлюз регистрирует расчётную стоимость запросов в своей SQLite. Платёжный контур сайта ведёт расчёты по своим правилам и хранит подтверждение в кабинете.
